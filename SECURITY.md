# Responsible security reporting

Please **do not** paste credentials, tokens, private keys, sensitive error messages, or proof-of-concept exploit payloads into public GitHub issues.

This repository contains public connection details only. The backing Workers are experimental services, not security certifications.

If you find a security concern, use GitHub's **private vulnerability reporting** feature if it is enabled for the repository. If that feature is unavailable, avoid publishing exploitable details until the repository owner has configured a suitable private reporting route.

Public tool endpoints do not request private credentials. Avoid sending sensitive inputs while the service is in beta.
